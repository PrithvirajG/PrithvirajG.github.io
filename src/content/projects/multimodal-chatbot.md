A scalable multimodal chatbot backend built with FastAPI, Redis (session
management), ChromaDB (vector storage), HuggingFace Embeddings
(all-MiniLM-L6-v2), and Llama-2 via llama-cpp-python. Addresses context-aware
dialogue with vector-indexed chat history retrieval, optimized embedding
latency, and distributed session state. Designed for future audio input via
Whisper and MCP adoption.
